# main-site/css

Two files, loaded in this order. Order matters: `app.css` uses tokens that
`theme.css` defines.

| File | Contains |
| --- | --- |
| `theme.css` | The theme system, copied from `uwuapps-theme.md` |
| `app.css` | Layout and components for this app only |

## theme.css

The portable theme spec, unchanged. Two independent axes that combine
freely: brand colour through `data-color-theme` on `<html>`, seven options,
and mode through `data-mode`, light or dark. Fourteen valid combinations,
all of which clear WCAG AA.

Do not edit this file to restyle the app. If a change belongs to every uwu
app it goes in `uwuapps-theme.md` first, then gets copied here. If it
belongs to this app it goes in `app.css`.

## app.css

Rules for this app. Every colour is a token:

| Need | Token |
| --- | --- |
| Card surface | `.glass`, or `--surface-strong` for nested controls |
| A fill that tracks the brand swatch | `--brand-fill`, `--brand-fill-strong` |
| Text on a brand tint | `--on-brand`, never `--brand-ink` |
| Headings, links, active foregrounds | `--brand-ink` |
| Secondary text on a card | `--muted` |
| Secondary text on `--surface-strong` | `--muted-strong` |
| Success, warning, error, in progress | `--ok`, `--warn`, `--error`, `--busy` |

There is exactly one hardcoded colour in this directory outside
`theme.css`: `#34c759` on the footer heart. The spec allows a fixed meaning
accent, and a heart has to read as a heart whichever swatch is active.

Status banners use the standard treatment, a 14 percent tint of the status
colour behind the colour itself, which is tuned to hold 4.5:1.

## Shape conventions

`.glass` surfaces 20px, cards and modals 16 to 20px, chips 999px,
rectangular buttons 12 to 14px, icon buttons 42px square and 34px with
`.small`. The layout column is 720px wide with 14px of padding, 10px under
480px. One breakpoint, `@media (max-width: 480px)`.
