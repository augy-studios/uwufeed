How it works

When a source is added, uwuFeed fetches it once and looks for a hub. A hub means the publisher announces new posts, so the source joins the push tier and is never polled. No hub means polling, with conditional requests and an interval that adapts between a minute and an hour.

That one check at signup is the whole difference between two second and thirteen minute latency, and it costs a single HTTP request.

Free, and built to stay that way

Sources are shared, so a thousand people following one channel is one fetch. The push tier costs nothing while idle, polling uses conditional requests and adaptive backoff, and dead feeds retire themselves. There is a donation link and nothing behind it.

Reset your password

A code arrives as a direct message, on Telegram or Discord if you have connected either, otherwise by email. Never in a group or a server channel. With nowhere private to send one, the password is reset to your username and shown here.

Or use a recovery code

The ten codes you were given when the account was made. Each works once, and they keep working even if you lose the Discord or Telegram account you connected.

Connect a chat

Link a Telegram chat so it shares these sources. Each source can then be sent to some destinations rather than all of them, from the Sources tab. It is also the only private way back into this account if you forget the password.

Linked services

Who you are on Telegram and Discord. This is where a password reset is sent, and it is what your servers are listed from.

Combine an account

A chat you used before signing in has its own sources. Combining brings them here. This cannot be undone.

Passkey

Sign out everywhere

Ends every signed in browser, phone and tablet, including this one. If you think somebody else has your account, this is the fastest way to take it back.

Delete account

Removes the account, everything it follows, its destinations, its linked services, its passkeys and its recovery codes. Sources themselves are shared and stay, because other people follow them. This cannot be undone.
